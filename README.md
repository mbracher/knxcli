# knxcli

knxcli could become a command-line toolkit for working with KNX installations from a terminal.
It could help installers, integrators, and automation hobbyists inspect a KNX bus without opening a full graphical engineering tool.
The tool might offer simple commands for discovering devices, listing group addresses, and reading live telegrams.
It could also provide safe write commands for testing actuators, switching lights, or adjusting simple datapoint values.
A scriptable interface would make it useful for diagnostics, smoke tests, and repeatable commissioning checks.
Human-readable output could make quick troubleshooting easier during on-site work.
Machine-readable output could let shell scripts and monitoring systems reuse the same commands.
Configuration profiles could store connection details for different projects or gateways.
Over time, knxcli could grow into a focused companion for KNX development, testing, and maintenance.
The goal would be a small, predictable utility that makes common KNX tasks faster from the command line.
